# 让AI写得像你

**Nicolas Cole为数百位商业领袖代笔十年，现在把方法教给AI。**

**核心发现："用我的声音写"是最没用的提示词。声音不是模糊感觉，是三个可观察变量。**

**三个变量：用词（口语还是专业）、句子长度（短而有力还是长而累积）、句子结构（直接断言还是反问还是碎片句）。**

**改1%的内容就能解决"这不像我写的"问题——不是整篇重写，是改掉几个具体用词。**

**银行写材料的AI味问题，本质也是同一个问题：你给AI的是模糊指令，不是具体样本。**

## 一、Cole是谁

1. **职业代笔人**：Nicolas Cole是数字写作创业者，Ship 30 for 30、Typeshare、Write With AI、Premium Ghostwriting Academy联合创始人。过去十年为300多位创始人、CEO、行业领袖代笔。
2. **他的生意**：帮商业领袖在LinkedIn、出版物上发表思想领导力文章——客户说想法，Cole写成文章，署客户的名。这是典型的"影子写手"。
3. **现在教AI做这件事**：他做了付费newsletter "Write With AI"，分享怎么用ChatGPT和Claude写得像自己。本质是把十年代笔经验，变成AI提示词方法。

## 二、他的核心方法

1. **声音不是感觉，是三个变量**：Cole把"写作声音"拆成三个可观察的维度——用词（口语还是专业、正式还是随意、字面还是比喻）、句子长度（短而有力、长而累积、还是两者混合）、句子结构（直接断言、反问、碎片句、故事、对比、列表、过渡）。
2. **不要说"写得像我"**：Cole说"听起来自信"这种提示完全没用。要给具体例子——你用哪些形容词？你不用哪些形容词？你的引用习惯是什么？你的节奏是什么？
3. **改1%就够了**：客户说"这不像我写的"，Cole不是整篇重写，而是改掉几个具体用词——一个词换了，整个语气就变了。小的、具体的偏好，胜过模糊的"用我的声音写"。
4. **建立个人语言模型**：写下你自己的真实经历、决策、失败、观察、观点。分离"大家都知道的知识"和"只有你知道的证据和原创观点"。把已批准的段落存起来，标注主题、日期、来源。让AI只检索和改编相关的已批准材料。审查每一个个人声明、数字、引用。把修正反馈回去。

## 三、五种客户声音原型

1. **讲故事的人（Storyteller）**：用故事开场，用叙事推进，结论藏在故事里。
2. **观点输出者（Opinionator）**：直接下判断，立场鲜明，不绕弯子。
3. **事实呈现者（Fact Presenter）**：用数据和事实说话，少观点多证据。
4. **框架构建者（Frameworker）**：喜欢用模型、矩阵、步骤来组织内容。
5. **爆粗口的人（F-Bomber）**：直接、粗鲁、不修饰，说人话。

Cole说，掌握这五种原型，就能给任何人代笔。银行内部也是这五种风格——总行风控处长是事实呈现者，支行行长是讲故事的人，产品总监是框架构建者。

## 四、对银行写材料的启示

1. **银行AI味从哪来**：让AI写监管汇报，出来的东西总是"随着数字经济快速发展，金融科技深度融合……"——这是因为你给AI的指令是"写一份AI金融应用的汇报"，没有给它你自己的写作样本。
2. **Cole方法的银行版**：把你过去写得最好的三份材料喂给AI，告诉它——这就是我的风格。然后具体告诉它：我不用"赋能""抓手""闭环"这些词，我喜欢用短句，我每个论点后面都跟一个数据，我结尾必须有风险提示。
3. **改1%**：AI写完的初稿，不要整篇重写。找出三个最不像你会说的词，换掉。整个材料的味道就变了。这比从头改效率高十倍。
4. **部门级风格库**：总行风控部有自己的话语体系——"审慎""穿透""实质重于形式"。可以建一个部门级的"风格样本库"，让AI写出来的材料自动带部门风格，而不是千篇一律的AI腔。

## 五、三个冷静判断

1. **AI能写得像你，但不能替你想**：Cole方法解决的是"怎么写"，不是"写什么"。银行材料的核心是观点和判断——AI可以模仿你的文笔，但不能替你做风控决策。
2. **风格是可以训练的，但版权和责任问题**：如果AI写的材料署了你的名，出了问题谁负责？Cole代笔是有客户授权的，银行用AI写材料也要走授权流程——AI只是工具，署名的人要负责。
3. **不要过度依赖AI风格迁移**：如果你自己都不写，光靠AI模仿你的风格，你的写作能力会退化。Cole的方法是"AI帮你写得更快"，不是"AI替你写"。

## 六、银行落地清单

1. **整理你的最佳写作样本**：从你过去写的材料里挑3-5份你自己最满意、最能代表你风格的，存成一个文件夹。这就是你的"个人语言模型"训练集。
2. **列出禁用词清单**：把你最讨厌的"AI味"词汇列出来——赋能、抓手、闭环、生态、矩阵、深度融合。每次AI写完，先搜这些词，全部换掉。
3. **明确句式偏好**：告诉AI你喜欢多长的句子。银行材料一般偏正式，但你可以要求"每段不超过三行，每段一个核心判断，后面跟数据"。
4. **部门风格对齐**：如果你写的是部门汇报，先把部门过去的优秀汇报喂给AI，让它学到部门的话语体系——风控部就该有风控部的语气，不要写成市场部的。
5. **初稿改1%**：AI写完不要整篇重写。找三个最不像你会说的地方，改掉。三个词换了，整个材料的味道就对了。

## 结语

Cole十年代笔经验告诉我们：让AI写得像你，关键不是写一个完美提示词，而是积累足够多的"你自己写的东西"作为样本。银行人用AI写材料，最高效的做法不是反复调提示词，而是把自己过去写得好的材料整理出来，做成一个"个人风格库"——AI有了样本，自然就像你了。
