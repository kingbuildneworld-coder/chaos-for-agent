# 让AI替你炒股

**美国券商 Public 自称全球第一个 Agentic Brokerage，让散户用自然语言生成自定义股票指数，并设定可循环执行的交易 Agent 自动盯盘下单。**

**技术上是把量化流水线拆成评估、回测、执行等多个 Agent，用户只负责用大白话描述想法和规则。**

**合规上把产品定位为自我导向的自动化指令，明确输出不构成投资建议，试图规避投顾的信义义务。**

**最大隐患是回测过拟合、算法同质化导致的羊群效应，以及自然语言降低门槛后散户承担超出其能力的复杂策略。**

**对银行而言，持牌、适当性、托管和投资者保护反而是护城河，Agent 理财必须把风控和适当性约束内置进系统。**

## 一、券商第一次把交易 Agent 交给散户

1. **产品定位**：Public 把自己定义为世界上第一个 Agent 化券商，用户可以管理投资组合、用 Agent 自动执行投资，而不是只看行情和手动下单。
2. **门槛被抹平**：过去需要写代码、懂量化才能实现的条件单和自动策略，现在用一句自然语言就能创建。
3. **工具下放**：散户拿到的是过去对冲基金才有的选股、回测和自动化执行能力，这是财富管理工具的一次民主化。
4. **银行的警觉**：当客户能让软件自动打理投资，传统理财经理和银行智能投顾的价值主张都要重新回答。

## 二、两个核心能力：生成式指数和交易 Agent

1. **生成式指数**：用户输入一个投资想法，比如高营收增长但薄利润、可能受益于人工智能的公司，系统就部署评估 Agent 扫描数千只股票，构建一个匹配意图的自定义指数。
2. **自动回测**：每个生成的指数都会自动对标主流指数做历史回测，展示历史回报和回撤，让用户直观看到策略过去表现。
3. **交易 Agent**：激活后，Agent 严格按用户定义的工作流执行，持续监控市场条件，只有在条件满足时才行动。
4. **典型策略**：包括每日定额买入、波动率监控加保护性看跌、备兑看涨、降息保护、通胀对冲等，覆盖定投、对冲和现金管理。
5. **本质是条件单**：Agent 并不会自己产生投资想法，它只是把用户预设的规则自动化，是更灵活的高级条件单而非自主决策。

## 三、技术原理：把量化流水线拆成 Agent

1. **分工对应**：评估 Agent 负责选股，回测 Agent 负责历史验证，执行 Agent 负责按条件触发，背后还有风险、审计和记忆组件。
2. **编排框架**：学术研究已提出把传统算法交易系统的规划、阿尔法、组合、执行、审计等模块全部映射成 Agent，再用统一协议编排。
3. **对话即配置**：用户不需要理解参数和代码，自然语言指令被翻译成 Agent 可执行的工作流。
4. **持续运行**：Agent 可以常驻、按计划或条件触发，把一次性的交易变成持续监控和循环执行。
5. **可审计设计**：每笔交易都对应一条明确的规则和触发记录，为后续核查提供依据。

## 四、关键合规设计：自我导向免责

1. **明确披露**：Public 在协议里写明，Agentic Brokerage 是自我导向的循环交易，输出仅用于信息和说明，不构成投资建议。
2. **法律边界**：通过把产品定性为用户自己设定的自动化指令，平台试图站在经纪业务而非投资顾问的位置，规避投顾的信义义务和适当性责任。
3. **有效性存疑**：一旦散户用自然语言创建复杂策略并出现大额亏损，监管和法院是否认可这种完全免责，仍是没有定论的前沿问题。
4. **责任认定难题**：Agent 出错时，责任在设定规则的用户、提供平台的券商，还是底层模型方，各方都在等监管给出答案。
5. **监管已在关注**：欧美和中国监管机构都在研究算法黑箱、责任认定、客户保护和金融基础设施韧性等问题。

## 五、回测为什么可能是海市蜃楼

1. **理想假设**：回测往往假设理想成交、忽略点差和延迟、把容量当成无限，实盘里这些假设都不成立。
2. **过拟合**：反复对历史数据优化，会得到统计上很有说服力、经济上却虚假的结果，策略记住了过去而非理解了市场。
3. **幸存者偏差**：只在现存股票上回测，自动忽略了已经退市的失败者，系统性高估收益。
4. **成本被忽略**：高换手策略税前看着诱人，算上佣金、点差和税费后可能根本不赚钱。
5. **制度漂移**：市场环境会变，历史上有效的规律在新的市场制度下可能突然失效，回测无法预测这种转折。

## 六、银行视角：适当性、羊群与责任

1. **适当性矛盾**：自然语言让缺乏经验的散户也能搭建期权和对冲策略，但这些策略可能远超其风险承受能力，适当性管理不能因为换了交互方式就放松。
2. **羊群效应**：大量用户问同一个模型、用相似的策略库，市场承压时众多 Agent 会方向一致地调仓止损，极端情况下放大波动，这是监管反复点名的系统性风险。
3. **过度依赖**：服务方和客户都可能盲目信任 AI，在复杂多变的市场里放弃人工判断，一旦黑箱出错很难及时纠偏。
4. **安全漏洞**：自动化交易依赖接口凭证和记忆层，凭证被盗或记忆层被注入都可能造成直接资金损失，需要和模型抗注入能力一起设防。
5. **银行的护城河**：持牌资质、适当性管理、资产托管、信义义务和投资者保护，是新平台短期难以复制的壁垒。
6. **可行方向**：银行应做把风控和适当性约束内置的合规 Agent 理财，在客户授权、额度、产品风险等级和人工复核上保留硬约束，而不是放任散户自由发挥。

## 七、四个冷静判断

1. **不是自主投资**：Agent 只执行用户预定义的规则，本质是高级条件单，离真正的 AI 自主决策还有距离。
2. **回测不等于未来**：漂亮的历史曲线可能是过拟合和偏差的产物，散户尤其要警惕把回测当成收益承诺。
3. **免责未必成立**：自我导向的法律标签在真实亏损纠纷中能否完全免责，还要等监管和司法实践检验。
4. **同质化是系统风险**：当相似 Agent 大规模同向交易，个体的理性自动化可能汇集成市场层面的顺周期踩踏。

## 八、和本站其他文章的呼应

1. **和让 Agent 安全地付钱呼应**：一个解决 Agent 怎么付款，一个解决 Agent 怎么投资，都是把金融核心动作交给自动化后的边界问题。
2. **和让模型分清敌我呼应**：交易 Agent 同样面临记忆层注入和凭证安全，模型级抗注入是金融 Agent 的共同底座。
3. **和买 Agent 还是造 Agent 呼应**：财富管理 Agent 无论自研还是采购，适当性、审计和责任可追溯都应是选型硬指标。

## 结语

Public 的 Agentic Brokerage 证明，把对冲基金级别的工具用自然语言交给散户在技术上已经可行，但工具的民主化不等于能力的民主化。散户拿到了选股、回测和自动执行的便利，却没有同时获得对冲基金赖以生存的风控、合规和纪律。对银行和监管来说，真正的考题不是要不要用 Agent，而是如何在降低门槛的同时守住适当性、约束羊群效应、厘清责任边界。在这些制度配套跑通之前，再顺滑的自动化体验，也不能替代投资者保护这条底线。
