# 高盛掐了交易员AI

**2026年11月2日Bloomberg报道：高盛禁止大多数员工使用Anthropic的Claude Code和微软的GitHub Copilot。**

**仅限约12000名工程师保留访问权，交易员和银行家被收回权限，内部指引10月已更新。**

**交易员此前用这些工具监控客户交易流、对头寸建模、制作分析内容，被禁后内部不满。**

**高盛经过生产力与风险评估，认为非工程岗位使用高级编程AI工具风险大于收益——信息泄露和合规风险压倒了效率提升。**

**这和上一篇"银行封锁外部AI助手碰客户账户"是同一条线的两面：银行既防外部Agent碰钱，也防内部员工用AI捅娄子。**

## 一、发生了什么

1. **高盛的内部政策**：高盛数月前允许银行家在工作中使用Claude Code和GitHub Copilot。经过生产力与风险评估后，10月更新内部指引，把这些工具的访问权限制在工程师群体。
2. **谁被收回了权限**：交易员、银行家（investment banking）、销售交易团队。他们此前用这些工具做：监控客户交易流、对市场变化和头寸建模、快速制作文字和图形内容。
3. **谁保留了权限**：约12000名工程师，以及"strats"团队（做量化的软件工程师）。发言人表示把工具"放在工程师手中"。
4. **内部反应**：被禁的交易员不满。他们已经习惯了用AI工具加速工作，突然收回相当于降低效率。

## 二、为什么高盛要掐

1. **信息泄露风险**：交易员把客户交易流、头寸数据、市场观点贴给外部AI工具（Claude、GitHub Copilot的云端模型），这些数据就离开了高盛的可控环境。客户数据和交易策略是银行的核心资产。
2. **合规风险**：交易员用AI生成的模型、分析、报告做交易决策，谁来审核？AI模型的输出是否经过合规审查？如果AI生成的模型有偏见或错误，导致交易亏损，责任算谁的？
3. **这些工具是"编程专用"的**：Claude Code和GitHub Copilot是给工程师写代码用的。交易员用它们写脚本、拉数据、做分析，本质是把编程工具当通用AI助手用，风险边界不清晰。
4. **生产力提升不明显**：评估后认为，非工程岗位用这些工具的效率提升，不足以覆盖信息泄露和合规风险的代价。

## 三、和上一篇文章的关系

1. **上一篇讲的是"防外"**：美国主要银行封锁第三方AI助手用客户密码访问账户，怕外部Agent碰钱。
2. **这一篇讲的是"防内"**：高盛收回内部员工用AI编程工具的权限，怕员工用AI捅娄子。
3. **内外两条线**：银行在AI治理上陷入两难——一方面想用AI提效，另一方面怕AI出事。高盛的选择是：AI工具只给工程师用，因为工程师有技术能力判断输出对不对；交易员和银行家没有这个判断力，用了风险太大。
4. **核心矛盾**：AI工具的效率提升是真实的，但风险也是真实的。高盛的答案是分级授权——不是所有人都能用同一种AI工具。

## 四、中国银行的对照

1. **同样的问题已经在发生**：中国银行的交易员、风控、客户经理也在私下用Claude、ChatGPT、Copilot写脚本、分析数据、写报告。高盛踩过的坑，中国银行也会踩。
2. **信息泄露是红线**：客户信息、交易策略、风险模型贴到外部云端AI，就是数据泄露。银行必须明确：哪些数据可以贴给AI，哪些不能。
3. **分级授权是方向**：不是一刀切禁用AI，而是按岗位和数据敏感度分级。工程师可以用编程AI（他们有技术判断力），交易员和风控要用银行内部部署的AI（数据不出行）。
4. **内部部署的AI才是答案**：高盛禁的是外部云端AI工具。如果银行有自己内部部署的大模型（数据不出行、操作可审计），交易员用内部AI做分析，风险就可控得多。
5. **不要只堵不疏**：交易员不满是因为效率被降低了。银行应该提供内部AI工具替代外部工具，而不是单纯收回权限。

## 五、三个冷静判断

1. **高盛的做法是保守的，但不是错的**：在风险和效率之间选保守，对银行来说是合理的。银行不是科技公司，试错成本太高。
2. **分级授权会成为行业标准**：未来银行的AI工具不会是"全员可用"或"全员禁用"，而是按岗位、按数据敏感度、按工具类型分级授权。工程师一个级别，交易员一个级别，客户经理一个级别。
3. **内部部署AI是银行的必选项**：外部云端AI工具再好用，银行也不敢让交易员用。数据不出行是底线。银行必须自建或采购内部部署的大模型，这比买API调用更贵，但更安全。

## 结语

高盛掐了交易员的AI工具，表面是效率倒退，实质是银行在AI治理上的一次重要抉择：当AI工具的效率提升和信息安全风险冲突时，银行选择安全。对中国银行来说，这不是远方的故事——你的交易员可能也在私下用外部AI工具。问题不是要不要管，而是怎么管：是一刀切禁用，还是分级授权加内部部署？这个选择，决定了银行未来五年能不能安全地用AI提效。高盛已经选了保守路线，中国银行呢？这是每个银行科技负责人都要回答的问题。
