# AI给客服备料

**2026年11月6日BMO发布AI Agent Assist，用于信用卡交易争议处理。**

**AI做三件事：自动匹配交易、检索政策条款、准备案件材料——客服员工审核后再回复客户。**

**规模：每年50万+信用卡来电，每通平均12-14分钟，目标减少20-30%通话时间。**

**关键设计：AI是辅助员工，不是直接面对客户——这是"人在回路"的Agentic AI。**

**BMO要把这个模式作为模板，推广到全企业其他业务线。**

## 一、这个案例到底做什么

1. **场景**：客户打电话到BMO客服，说"这笔1200元的交易不是我刷的"。客服员工需要查交易记录、查政策、准备材料、回复客户。
2. **AI做什么**：AI Agent自动把客户提到的交易和系统里的记录匹配上，检索相关的争议处理政策，把案件材料整理好，直接推到客服员工的屏幕上。
3. **人做什么**：客服员工审核AI准备的材料，然后和客户通话回复。不需要客户在电话里等员工翻系统。
4. **效果目标**：现在每通电话平均12-14分钟，目标减少20-30%，预计40%的符合条件的来电能用上这个AI工具。

## 二、为什么这是好的Agentic AI落地

1. **不是替代人，是辅助人**：OCC上周刚出监管框架，把自主支付Agent列为Tier 1最高风险。BMO这个案例是"AI备料、人来回复"——人在回路里，风险可控。
2. **具体场景，不是泛泛而谈**：信用卡争议处理是银行客服最常见、最耗时的场景之一。AI在这里落地，ROI很清晰——省时间就是省钱。
3. **AI做的是它擅长的**：匹配交易、检索政策、整理材料——这些是搜索和模式识别，AI比人快。和客户沟通、判断特殊情况——这些是人做。
4. **BMO的野心**：Greg Brown（企业AI转型和首席数字官）说，要把这个作为模板推广到全企业。这不是一个试点，是一个可复制的模式。

## 三、对中国银行的启示

1. **客服是AI落地的最佳场景**：中国银行客服每年处理海量来电——信用卡争议、账户查询、密码重置。这些场景AI备料、人来回复，风险低、效果好。
2. **不要一上来就做全自动**：很多银行想做"AI客服全自动接电话"，但风险高。BMO的路径是对的——先做AI辅助员工，等员工信任了、准确率够高了，再逐步开放更多自动化。
3. **具体数据很重要**：BMO给了50万来电、12-14分钟、30%降幅这些数字。中国银行做AI客服，也要有这样的基线数据——现在每通电话多长？AI介入后降了多少？没有基线就没有效果。
4. **"备料"比"回复"更安全**：AI准备材料给员工看，出错了员工会发现。如果AI直接回复客户，出错了就是客户投诉。先做备料，是低风险的第一步。

## 四、和OCC框架的对应

1. **OCC把"Agent发起客户沟通"列为Tier 2（高风险）**：BMO这个案例正好在Tier 2——AI辅助员工和客户沟通，不是AI直接和客户沟通。
2. **OCC把"欺诈冻结释放"列为Tier 1（最高风险）**：信用卡争议处理涉及欺诈判断，BMO让AI准备材料但不做最终决定——这个设计符合监管要求。
3. **OCC说"按后果评风险，不按技术复杂度"**：BMO用的AI技术不复杂（匹配+检索+整理），但用在信用卡争议这种高风险场景，所以人在回路。这就是OCC框架的实际应用。

## 五、三个冷静判断

1. **30%降幅是目标，不是结果**：BMO说的是"targeting"（目标），不是已经实现。银行做AI项目要小心——目标和实际效果可能差很远。
2. **40%覆盖率是个限制**：只有40%的来电能用上这个AI工具。剩下60%可能是复杂案件、特殊情况——这些还是要人处理。AI不是万能的。
3. **可复制性待验证**：BMO说要推广到全企业，但信用卡争议处理是标准化场景。换个场景——比如财富管理、贷款审批——AI备料的难度会大很多。

## 六、银行落地清单

1. **选最标准化的客服场景先做**：信用卡争议、密码重置、账户查询——这些流程固定、数据结构化，AI最容易落地。
2. **先做备料，不做回复**：AI把信息整理好推给员工，员工看完再和客户说。不要一开始就让AI直接面对客户。
3. **测基线再上AI**：现在每通电话多长？员工平均查几次系统？客户等多久？这些基线数据要先测，AI上线后才能对比效果。
4. **员工培训很重要**：AI准备的材料员工要会看、会判断、会纠错。如果员工盲目信任AI，AI出错就是客户投诉。
5. **一个场景跑通再复制**：不要一上来就全银行推广。信用卡争议跑通了，再复制到其他场景。每个场景都要重新测基线、重新调AI、重新培训员工。

## 七、和本站其他文章的呼应

1. **和OCC框架呼应**：OCC说按后果评风险，BMO这个案例正好是Tier 2——AI辅助员工和客户沟通，人在回路里，符合监管要求。
2. **和Claude Personal Finance呼应**：Claude是AI公司直接连银行账户（只读），BMO是银行自己用AI辅助员工。一个从外往里打，一个从里往外做——两条路径。
3. **和美国银行封AI助手呼应**：美国银行不让员工用外部AI，BMO自己建内部AI工具。封外部不如建内部——这是BMO的思路。

## 结语

BMO这个案例最值得注意的不是AI技术有多先进，而是它落地的方式：选一个高频、标准化、耗时的场景，让AI做它最擅长的（匹配、检索、整理），人做它最擅长的（判断、沟通、特殊情况）。这就是银行Agentic AI的正确打开方式——不是让AI替代人，是让AI给人备料。
