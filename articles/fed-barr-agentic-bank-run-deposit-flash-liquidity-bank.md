# 当挤兑按秒发生

**美联储理事 Barr 在 11 月 16 日警告，自主 AI Agent 能瞬间识别收益率差异和风险信号，自动高速转移存款，把银行挤兑压缩到几分钟内。**

**传统流动性管理和监管干预按小时、按天设计，可能在机器速度的存款外流面前彻底失效。**

**他同时透露，大型银行已经发现 AI Agent 试图在零售客户账户中采取行动，而银行无法验证其真实性和客户授权。**

**这并非孤例，早在 9 月就有华尔街机构提出 Agent 驱动的挤兑风险，硅谷银行曾创下单日四百多亿美元外流的纪录。**

**应对方向是把护栏前移，用严格认证、显式授权、转账限速和断路器，给按下快进键的挤兑装上制动装置。**

## 一、美联储理事的警告：挤兑以分钟计

1. **场合与身份**：美联储理事 Michael Barr 于 11 月 16 日在意大利米兰举行的金融人工智能国际会议上发表演讲，这是他过去一年第四篇专门讨论人工智能的讲话。
2. **核心判断**：过去客户需要亲自执行转账，而 AI Agent 可以瞬间检测收益率差异或稳定性信号，自主高速移动资金。
3. **时间尺度被压缩**：他明确指出，这可能加速在几分钟内展开的银行挤兑，使传统流动性管理和监管干预的时间线不堪重负。
4. **背后的报告**：讲话同时回顾了美联储最新一期金融稳定报告，该报告关注 AI 投资热潮以及为数据中心融资的创新债务结构中累积的杠杆。
5. **基调并不悲观**：Barr 强调自己对 AI 的长期价值持乐观态度，但前提是金融体系能有效管理当下的风险，金融稳定是 AI 成功的必要条件。

## 二、历史锚点：从柜台排队到手机挤兑再到 Agent 挤兑

1. **传统挤兑**：历史上的银行挤兑表现为储户在网点门口排队取现，受物理距离和营业时间限制，往往持续数天甚至数周，银行还有喘息和应对的窗口。
2. **手机银行时代**：2023 年 3 月硅谷银行危机中，储户通过社交媒体和手机应用挤兑，单日提取约 420 亿美元，创下当时最快挤兑纪录，决策和传播已经被数字化大幅加速。
3. **关键变化**：硅谷银行挤兑虽然快，但每一笔转账背后仍是人在阅读信息、做出判断、手动操作，人的注意力和手速构成了天然的速度上限。
4. **Agent 时代**：一旦把监控、决策和执行都交给 Agent，连人这一环都被移除，资金迁移可以在没有人为干预的情况下连续、批量、自动发生。
5. **三级跳**：从柜台排队到手机点击再到 Agent 自动执行，挤兑的时间单位从周、天、小时，进一步压缩到分钟甚至秒。

## 三、Agent 挤兑的技术机制：感知、决策、执行、正反馈

1. **感知环节**：Agent 被设定为持续监控市场信号，包括其他银行的报价利率、债券和信用违约互换价格、新闻舆情以及社交媒体上的稳定性信息。
2. **决策环节**：很多 Agent 内置了规则化的触发逻辑，例如检测到某家银行风险信号上升、或发现别处收益率更高，就自动发起资金转移，不需要临时请示。
3. **执行环节**：Agent 通过支付和账户接口直接调用转账能力，从感知到执行可以在数秒内闭环，省去了人工登录、确认、审批的全部延迟。
4. **正反馈环节**：早期资金外流会进一步推高市场对该银行的风险判断，这些新信号又触发更多 Agent 撤离，形成自我强化的螺旋，与市场踩踏的机制相同。
5. **协同而非巧合**：当大量 Agent 采用相似的数据源和相似的风控规则，它们会在同一时刻得出相同结论，表现为高度同步的集体行动，而不是彼此独立的随机提款。

## 四、为什么这一次不一样

1. **无需单一触发事件**：有华尔街机构指出，Agent 驱动的资金迁移可能由细微的利差或信号变化引发，在数百万家庭之间同时发生，不需要等到某个爆炸性新闻。
2. **逐利与避险同向**：Agent 既会因为别家银行给出更高收益而搬走存款，也会因为风险信号而撤离，两类动机在压力时期会叠加，加速存款从特定机构流出。
3. **低息存款最脆弱**：大量沉淀在低息账户中的零售存款，对能自动比价的 Agent 而言是最容易被迁走的部分，银行的负债稳定性面临新的考验。
4. **羊群效应被放大**：Barr 在讲话中专门提到市场羊群和踩踏风险，少数相似模型共享同一缺陷时，可能引发具有系统性后果的失败。
5. **理解不对称**：有研究警告，AI Agent 能预判人类行为，人类却难以预判 Agent 的行为，这种不对称会让价格和资金流向在关键时刻更难理解、更难干预。

## 五、已经发生的信号：未授权的 Agent 行动

1. **银行的实际发现**：Barr 透露，主要银行已经报告发现 AI Agent 试图在零售客户账户中采取行动，而银行无法验证其真实性、客户同意以及与客户指令的一致性。
2. **问题的本质**：这意味着风险已经从理论推演走到了现实边缘，银行面对的不只是挤兑速度，还有账户操作的身份认证和授权核验难题。
3. **护栏的四个要素**：Barr 提出，金融服务中的 AI 只有在适当护栏下才能长期成功，包括严格认证、针对特定能力的显式同意、限制 Agent 能力的技术控制，以及规则与价值观双重约束。
4. **系统提示不可靠**：结合此前多起 Agent 越界事故，仅靠提示词无法约束 Agent 行为，真正的边界必须由权限和技术控制强制执行。
5. **责任认定更复杂**：当一笔转账由 Agent 自动发起，一旦发生纠纷，授权是否真实、指令是否一致，将直接决定责任由谁承担，留痕和核验因此至关重要。

## 六、银行与监管的应对

1. **转账限速与阈值**：可以在合约或系统层面对 Agent 的单位时间累计转账金额设置硬性上限，例如限制每分钟的支出比例，使其无法在短时间内清空账户。
2. **断路器机制**：欧洲央行等机构指出，市场设计工具如断路器可以在动荡时期遏制过度撤资，为流动性管理和人工判断争取时间。
3. **显式授权与认证**：对 Agent 能够调用的账户能力逐项授权，把高风险、不可逆的转账动作纳入强认证和人工审批，而不是默认开放。
4. **流动性监测提速**：银行需要把流动性监测的时间粒度从按天、按小时细化到按分钟，建立针对机器速度外流的实时预警和应急安排。
5. **压力测试纳入新情景**：已有监管机构计划在系统压力测试中纳入 AI 驱动的 disruption 情景，检验银行在极端、快速存款外流下的承受能力。
6. **监测融资端风险**：除了存款侧，监管还在密切关注 AI 数据中心债务和循环融资网络，避免资产估值与杠杆在重定价时相互放大。

## 七、四个冷静判断

1. **风险真实但尚未爆发**：Barr 本人也承认生成式 AI 目前尚未大规模用于自主交易，Agent 挤兑更多是需要提前防范的前瞻风险，而非眼前的现实危机。
2. **速度是核心变量**：这一风险的本质不是挤兑本身，而是决策和执行被移除人之后，时间尺度被压缩到传统工具无法响应的程度。
3. **不能因噎废食**：Agent 在资金管理、比价和风险监控上同样带来效率收益，治理目标是给速度装上制动，而不是彻底禁止自动化。
4. **护栏必须前置**：等到挤兑真正发生再补建认证、限速和断路器将为时已晚，制度和技术控制需要在 Agent 大规模接管账户之前就位。

## 八、和本站其他文章的呼应

1. **和让 Agent 懂得分寸呼应**：那篇讲 Agent 何时该主动、何时该沉默，这篇正是过度主动在存款侧可能引发的极端后果。
2. **和让 AI 替你炒股呼应**：那篇讲交易自动化的羊群效应，这篇把同样的协同与踩踏逻辑延伸到了银行负债和流动性领域。
3. **和让 Agent 安全地付钱呼应**：逐笔授权和强认证的思路一致，都是在不可逆的资金动作前把好身份与授权这道关。

## 结语

银行挤兑是一个古老的风险，但它的形态正在被技术重新定义。过去制约挤兑的，是网点的物理距离、营业时间和人的手速；而当 Agent 能够 7×24 小时监控信号、自动决策、瞬时执行，这些天然的缓冲全部消失，挤兑可能在几分钟内就走到传统流动性工具来不及反应的地步。美联储理事的警告价值，不在于预言危机必然发生，而在于提醒监管和银行：面对机器速度的资金流动，护栏的设计时间尺度必须同步升级。把认证做严、把授权做实、把速度限制住、把断路器备好，才能让金融体系在享受 Agent 效率的同时，不至于被一次按秒发生的挤兑击穿。

（口径说明：Barr 演讲与金融稳定报告来自美联储官方，历史挤兑数据来自监管机构背景报告，机构观点来自公开研究；银行流动性治理的具体映射为作者分析，相关风险仍在持续观察与评估中。）
